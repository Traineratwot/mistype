## Шаг 1 — Версия + проверка обновлений (п.1)

### Версия
- `crates/mistype-daemon/src/main.rs:14` — в `about` добавить версию:
  `concat!("Fix text typed in the wrong keyboard layout (v", env!("CARGO_PKG_VERSION"), ")")`.
  `--version` уже работает через clap.
- `doctor` — заголовок: `Mistype doctor (v2.0.0)` (`doctor.rs:13`, `env!("CARGO_PKG_VERSION")`).

### UpdateChecker (новый port)
- `crates/mistype-app/src/ports.rs`:
  ```rust
  pub enum UpdateStatus { UpToDate(String), Available(String), Unavailable(String) }
  pub trait UpdateChecker: Send + Sync {
      fn check(&self) -> UpdateStatus;   // sync — doctor one-shot, blocking нормален
  }
  ```
- Реализация `crates/mistype-adapters/src/platform/portable/update_check.rs` (новый файл —
  реальный шов): `ureq` GET `https://api.github.com/repos/Traineratwot/mistype/releases/latest`,
  заголовки `User-Agent: mistype/{version}` и `Accept: application/vnd.github+json`
  (GitHub API требует UA). Парс `tag_name` (срезать `v`, сравнить `(u64,u64,u64)` с
  `CARGO_PKG_VERSION` — без semver-крейта). Timeout ~5 с. Любая ошибка → `Unavailable`.
- Doctor-строка `update`:
  - `OK "up to date (2.0.0)"` / `OK "update available: v2.1.0"` / `OK "check skipped (offline)"`.
  - **Сетевой сбой НЕ делает check FAIL** — offline не дефект продукта, а `all_ok()` рулит UX
    setup. Информационная строка всегда `ok=true`.
- `--help`/`--version` сеть **не** дёргают (только статическая версия).

### Приватность (исключение — задокументировать)
AGENTS/PRIVACY говорят «нет сети кроме LLM endpoint». Проверка обновлений — явное
действие пользователя (`mistype doctor`), только GitHub Releases, без телеметрии.
Обновить `docs/PRIVACY.md` и AGENTS.md Privacy: отметить это исключение.

## Шаг 3 — UI: textarea, «Вставить», «Сбросить» (п.2–4)

Файл: `crates/mistype-ui/src/settings_app.rs` (Elm-style, `Message` :102-136, `update` :232,
`view` :766).

### 3a. Системный промпт → textarea
- iced 0.13 `text_editor` + `text_editor::Content` (уже в workspace-депе `iced 0.13`,
  доп. фичи не нужны). `text_input` однострочный — не подходит.
- State: `system_prompt_content: text_editor::Content` в `SettingsApp`.
  - Создаётся один раз из `cfg.llm.system_prompt` при старте и при «Перезагрузить конфиг».
  - `Message::PromptEditor(text_editor::Action)` → `content.edit(action)`, затем
    `cfg.llm.system_prompt = content.text()`.
  - **Пересоздавать `Content` только** при: сбросе, вставке из буфера, reload-конфига.
    Никогда в `view()` — иначе прыгает курсор и теряются правки.
- Вид: label + `text_editor(...).height(Length::Fixed(120.0))` + hint, в `row!` с кнопками
  «Вставить» и «Сбросить».
- `def_llm_system_prompt` (`config.rs:269`) → `pub fn default_llm_system_prompt()` —
  кнопка «Сбросить» ставит его в `cfg.llm.system_prompt` и пересоздаёт `Content`.
