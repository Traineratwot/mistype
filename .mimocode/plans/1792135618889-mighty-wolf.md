# Phase 2 — Спеллчек + подсказки (SwitchFix)

## UX-концепция

На Wayland/KDE нельзя показать попап «у слова» (композитор не отдаёт каретку).
Поэтому — **полоса подсказок внизу экрана** (как IME-строка на телефоне) + глобальные хоткеи.

### Три режима (`spell.mode`)

| Режим | Поведение |
|-------|-----------|
| `hint` (дефолт) | Пассивные подсказки в полосе; принять — клик или `Ctrl+1/2/3` |
| `hotkey` | Полоса выкл.; `Ctrl+F2` — мгновенно исправить последнее слово |
| `auto` | Уверенные опечатки правим молча; неуверенные — в полосу |

### Два источника подсказок

1. **Дописывание** — после 3+ символов текущего слова: 3 варианта из словаря.
2. **Орфография** — на границе слова (space/пунктуация): слово неверно → 3 варианта.
   Плюс **сквозная проверка раскладки**: `ghbdtn` → «1. привет (раскладка)» — конверт EN↔RU
   как кандидат №1, если после конверта слово становится корректным. Это killer-feature.

### Полоса (layer-shell, bottom)

- Невидима, пока нечего предлагать; не крадёт фокус (клик + глобальные хоткеи).
- Слоты: `1. кандидат  2. кандидат  3. кандидат  ·  +в словарь`.
- Принять: клик по кандидату или `Ctrl+1/2/3` (только пока полоса видима).
- Скрыть: таймаут (~4.5 с), `Ctrl+.` / Esc-подобное действие, новое слово.
- `+в словарь` = `Ctrl+0` или клик — в `user.dic`.

### Поведение принятия

`backspace(char_len)` + `type_text(кандидат)` (существующий `TextInjector`).
Регистр исходного слова сохраняется. Клипборд не трогаем (как word-path).

**Звук:** после успешной замены слова — короткий сигнал (как hotkey-sound:
`play_hotkey_sound` в `feedback.rs`, reuse + отдельный звук `spell-fix`).
Срабатывает и при accept с полосы, и при `Ctrl+F2`, и при auto-fix.
Громкость/выбор звука — тот же best-effort путь (canberra-gtk-play / paplay).
Опция `spell.sound = true` (дефолт) — отключить для тихого режима.

ui (полоса, settings)  →  app (SpellService, ports)  →  domain (чистая эвристика)

### Domain — `switchfix-domain/src/spell.rs` (новый, pure)

Только логика без I/O:

```rust
enum SuggestionKind { Completion, SpellFix, LayoutConvert }

struct Suggestion { text: String, kind: SuggestionKind, source_word: String }

fn should_check(word: &str, min_len: usize) -> bool
    // skip: digits, ALLCAPS (акронимы), URL/символы, len < min_len

fn is_auto_fixable(suggestions: &[Suggestion], word: &str) -> bool
    // единственный кандидат && edit_distance ≤ 2 && word.len() ≥ auto_fix_min_len

fn rank(word: &str, mut candidates: Vec<Suggestion>) -> Vec<Suggestion>
    // LayoutConvert first, then edit-distance, then frecency-ready order

fn preserve_case(original: &str, replacement: &str) -> String
```

Типы `Suggestion`, `SuggestionKind` живут здесь. Решение «какие кандидаты» — app.

### App — порты (`switchfix-app/src/ports.rs`)

```rust
#[async_trait]
pub trait SpellChecker: Send + Sync {
    fn is_correct(&self, word: &str, lang: &str) -> bool;
    fn suggest(&self, word: &str, lang: &str, n: usize) -> Vec<String>;
    fn add_to_dictionary(&self, word: &str) -> Result<(), SpellError>;
    fn languages(&self) -> Vec<String>;
}

#[async_trait]
pub trait SuggestionPresenter: Send + Sync {
    async fn show(&self, model: SuggestionUi) -> Result<(), NotifyError>;
    async fn hide(&self) -> Result<(), NotifyError>;
    fn is_visible(&self) -> bool;
}

// расширение TypingBufferPort:
fn peek_current_word(&self) -> Option<String>;   // дописываемый фрагмент
fn word_events(&self) -> broadcast::Receiver<WordEvent>;
// WordEvent::Completed(WordSpan) — слово окончено (набран разделитель)
// WordEvent::Updated(String)    — символы добавлены (для completion)
```

`SuggestionUi` — payload для полосы: `slots: Vec<Suggestion>`, `can_add_to_dict: bool`,
`original: String`, `timeout_ms`.

### App — `switchfix-app/src/services/spell.rs` (новый)

`SpellService` — оркестрация:

1. Подписка на `WordEvent`.
2. **Completed**: `should_check` → `SpellChecker::suggest` + `ConversionSet::convert`
   как LayoutConvert-кандидат → `rank` → auto-fix? → `SuggestionPresenter::show`.
3. **Updated**: длина ≥ `completion_min_chars` → completion-кандидаты → `show`.
4. **Accept(slot)** / **AcceptHotkey(n)**: `TextInjector::backspace + type_text`, `hide`, **сигнал**.
5. **AddToDict**: `SpellChecker::add_to_dictionary`, `hide`.
6. **FixLastWord** (Ctrl+F2): тот же путь без UI — top-1 сразу + **сигнал**.
7. Уважает `enabled`, `excluded_apps`, `disable_in_fullscreen` (через `FocusMonitor`).

### Adapters

| Файл | Роль |
|------|------|
| `platform/portable/zspell_dict.rs` | `SpellChecker` на **zspell** (pure Rust). Словари `/usr/share/hunspell/{ru_RU,en_US}.{aff,dic}` + `~/.local/share/switchfix/user.dic`. Отсутствие словаря → warn + `is_correct=true` (не спамим). |
| `platform/portable/typing_buffer.rs` | `peek_current_word` + `word_events` (уже `push_char`; на разделителе — `Completed`). |
| `switchfix-ui/src/suggestion_bar.rs` | Полоса. **iced + `iced_layershell`** (bottom strip). Отдельный tokio-поток в daemon (как ksni-tray). Fallback без layer-shell: always-on-top окно по центру-низу + warning. |
| `platform/portable/log_notifier.rs` | без изменений (fallback, если полоса не поднялась) |

### Config — `[spell]` + хоткей

```toml
[spell]
enabled = true
mode = "hint"                  # off | hint | auto
languages = ["ru", "en"]
min_word_len = 3
completion_min_chars = 3
suggest_count = 3
bar_position = "bottom"        # bottom | top
bar_timeout_ms = 4500
auto_fix_min_len = 4
sound = true                   # короткий сигнал при исправлении слова

[hotkeys]
fix_spelling = "ctrl+f2"
# accept: ctrl+1..suggest_count — регистрируются ТОЛЬКО пока полоса видима
# add_to_dict: ctrl+0 (пока полоса видима)
# dismiss: ctrl+period
```

Валидация `mode`, `languages`, диапазонов — в `AppConfig::validate()`.

### Hotkey / evdev

- `HotkeyEvent` += `FixSpelling`, `AcceptSuggestion(u8)`, `AddToDictionary`, `DismissSuggestions`.
- Динамический матчер: общие `bar_visible: AtomicBool` / watch — когда false,
  `Ctrl+1/2/3/0` и `Ctrl+.` **не** перехватываются (не мешаем приложениям).
- `Ctrl+F2` — постоянный, как `ConvertSelection`.

### UI / Settings

Новая страница **«Правописание»** (`settings_app.rs`):
переключатель, режим (radio), языки, длина слова, auto-fix, позиция полосы,
таймаут, хоткей `fix_spelling` (click-to-capture), управление `user.dic`
(список + удалить). Строки — на русском.

### Daemon / wiring

`wiring.rs`: `create_platform` → `ZspellDictionary::load()` → `SpellService` →
поток `suggestion_bar` → daemon loop: при `WordEvent` / `HotkeyEvent::FixSpelling` / accept — вызовы SpellService.

`doctor`: пункты «словари ru/en», «user.dic», «layer-shell / полоса».

### CLI (опц.)

`switchfix spell --text 'привет'` → `корректно` / `варианты: …` (отладка без UI).

## Риски и митигация

| Риск | Митигация |
|------|-----------|
| Wayland: нельзя двигать окно «к мыши» | layer-shell **bottom/top** strip (не popup у каретки) |
| `iced_layershell` / winit-API не совпал | Fallback: всегда topmost окно по центру-низу; слоты — через `SuggestionPresenter` (порт) |
| iced в daemon vs ksni event loop | Полоса — **отдельный поток** (как tray worker), не main |
| 100% точность словарей | user.dic; `should_check` режет шум; auto-fix только при высокой уверенности |
| `Ctrl+1` конфликтует с IDE | accept-бинды активны **только** пока `bar_visible` |
| zspell ≠ hunspell по морфологии RU | Проверить на `ru_RU.dic`; fallback — hunspell-rs FFI (за портом) |
| Приватность | Слова только в RAM; сеть отсутствует; не пишем текст в логи |
