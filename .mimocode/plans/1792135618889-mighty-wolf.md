# Fix: язык подсказок + KDE-виджет в панели

## Проблемы

### 1. Подсказки «не понимают» язык (root cause)

`key_to_char` в `evdev_hotkey.rs` жёстко мапит физические keycode → **латиницу US**.
Когда пользователь печатает в RU-раскладке:

| На экране | В буфере | `detect_lang` | Словарь |
|-----------|----------|---------------|---------|
| `привет` | `ghbdtn` | `en` | EN — ошибка |
| `приветт` | `ghbdtnn` | `en` | EN — мусор вместо «привет» |

Отсюда «программа не знает, на каком языке я пишу» и английские подсказки
при русском вводе. (Кли `switchfix spell --text` работает, потому что туда
попадает уже готовая строка.)

**Корень:** буфер должен хранить **символы текущей раскладки**, а не
физические US-клавиши. Маппинг QWERTY→ЙЦУКЕН уже есть в домене
(`en_to_ru_map()`), индекс текущей раскладки — в `KdeLayoutSwitcher`
(`getLayout` / `layoutChanged`).

### 2. Floating-окно

Перекрывает окна, теряется при переключении. **Удаляем UI-окно**
(`suggestion_bar.rs` как iced-приложение). CLI `switchfix suggest-bar`
остаётся как фолбэк.

**Новое место подсказок:** Plasma-виджет в панели (полоса кандидатов).

## A. Layout-aware клавиши (главный фикс)

### A1. `LayoutCharMapper` (portable, pure-ish)

`crates/switchfix-adapters/src/platform/portable/layout_chars.rs`:

```rust
pub struct LayoutCharMapper {
    layout_ids: Mutex<Vec<String>>,  // ["us","ru"] — из getLayoutsList
    current: AtomicU32,              // индекс из getLayout / layoutChanged
    us_to_ru: HashMap<char, char>,   // en_to_ru_map()
}

impl LayoutCharMapper {
    /// keycode+shift → символ ТЕКУЩЕЙ раскладки.
    pub fn map_key(&self, latin: char) -> char {
        let id = self.current_id();          // "us" | "ru" | …
        if id.starts_with("ru") {
            self.us_to_ru.get(&latin).copied().unwrap_or(latin)
        } else {
            latin   // us и прочие — как есть (док: ua и др. без маппинга)
        }
    }
    pub fn set_layouts(&self, ids: Vec<String>);
    pub fn set_current(&self, index: u32);
}
```

`key_to_char` (US) остаётся в evdev; результат прогоняется через
`mapper.map_key()` перед `buffer.push`.

### A2. Wiring (kde/mod.rs)

1. `getLayoutsList()` → `mapper.set_layouts([...])`
2. `getLayout()` / сигнал `layoutChanged` → `mapper.set_current(i)`
   (уже есть `KdeLayoutSwitcher::subscribe()`)
3. Передать `Arc<LayoutCharMapper>` в `EvdevOptions` → `run_loop`

### A3. Evdev loop

```rust
if let Some(latin) = key_to_char(code, shift) {
    buffer.push(mapper.map_key(latin));
}
```

### A4. Тесты

- unit: RU layout → `g`→`п`, `h`→`р`, … (`"ghbdtn"` keys → `"привет"`)
- unit: US layout → без изменений
- unit: Shift + RU → заглавные
- unit: неизвестная раскладка → latin as-is
- SpellService: `on_word_event(Completed { "приветт" })` → русские кандидаты
  (не EN)

## B. KDE-виджет панели (плазмоид)

### B1. Пакет `packaging/plasmoid/org.switchfix.suggestions/`

```
metadata.json          # Id=org.switchfix.suggestions, X-Plasma-API-Minimum-Version=6.0
contents/ui/main.qml   # PlasmoidItem
contents/ui/config.qml # (опц., позже)
```

### Внешний вид виджета (детально)

Пользователь ставит виджет **в панель** («строка состояния»). Ведёт себя
как «IME-строка»: живёт в панели, не всплывает окном, не перекрывает
приложения.

#### Состояние 1 — «спим» (нет подсказок)

```
┌─────────────────────┐
│   [SF]              │   ← compact icon, ширина ~панельной иконки (24–32 px)
└─────────────────────┘
```

- Иконка `preferences-desktop-spellcheck` (или наша `switchfix.svg`).
- Цвет — обычная (не accent), opacity 0.55 — «ничего не происходит».
- Tooltip: `SwitchFix — подсказок нет`.
- Клик ЛКМ = Toggle enabled (как треь).
- В этом состоянии **никаких** кнопок и текста в панели.

#### Состояние 2 — «подсказки» (есть кандидаты)

Панель расширяется, слева направо:

```
┌──────────────────────────────────────────────────────────────────────┐
│  «приветт»   [1 привет]  [2 привету]  [3 приветы]  [+словарь]  [✕] │
└──────────────────────────────────────────────────────────────────────┘
     ↑           ↑            ↑            ↑            ↑          ↑
   серый      accent      secondary    secondary     secondary   ghost
   italic     button      button       button        button     button
```

| Элемент | Вид | Действие |
|---------|-----|----------|
| `«приветт»` | серый *курсив* 11–12 px, префикс «исправить:» опц. | нет (контекст) |
| `[1 привет]` | **accent** (выделен — «лучший кандидат»), префикс `1 ` | accept slot 1 |
| `[2 привету]` | secondary/ghost, префикс `2 ` | accept slot 2 |
| `[3 приветы]` | secondary/ghost, префикс `3 ` | accept slot 3 |
| `[+словарь]` | ghost, иконка `bookmark-new` или текст | learn word |
| `[✕]` | ghost, только иконка `dialog-close` | dismiss |

**Размеры / типографика (Plasma Units):**
- Высота = толщина панели (`Layout.fillHeight`), кнопки `flat: true`.
- Шрифт кандидатов: `PlasmaCore.Theme.defaultFont` (11–12 px).
- `«исходное слово»`: `theme.disabledTextColor`, `font.italic: true`.
- Отступы: `spacing: PlasmaCore.Units.smallSpacing` (4 px).
- Максимум **3** кандидата (из `spell.suggest_count`); если меньше —
  пустые слоты не рисуются.
- Длинные слова: `elide: Text.ElideRight`, `Layout.maximumWidth: 12 * em`.

**Цвета:**
- Кандидат №1 — `Kirigami.Theme.highlightColor` (или `button-accent`).
- Остальные — обычные кнопки панели, без заливки (`flat`).
- При наведении — стандартный hover панели (не свой).
- `+словарь` / `✕` — иконки без текста, если ширина панели мала
  (`Plasmoid.formFactor === Horizontal && width < threshold`).

**Адаптация к ширине панели:**

| Ширина | Вид |
|--------|-----|
| ≥ 280 px | Полная полоса (текст исходного слова + 3 кнопки + ✕) |
| 160–280 px | Только `[1] [2] [3]` без исходного слова и `+словарь` |
| < 160 px | Только `[1 привет]` + счётчик `+2` (открывает popup) |

#### Состояние 3 — «popup» (по клику на иконку / при тесноте)

`Plasmoid.fullRepresentation` / `plasmoid.expanded = true` — не окно
поверх, а **стандартный popup плазмоида** (прижат к панели, закрывается
по Esc / клику мимо, не перекрывает как отдельное окно):

```
┌──────────────────────────────────┐
│ Исправить: «приветт»             │
│                                  │
│  1  привет          Enter        │
│  2  привету                     │
│  3  приветы                     │
│                                  │
│  [+ в словарь]        [Пропустить] │
└──────────────────────────────────┘
```

- Список = `ListView`, выделение мышью/стрелками, Enter = accept.
- Это **тот же** popup, что и у других плазмоидов (не floating-window).
- В режиме «спим» popup: короткая сводка («Подсказок нет», язык, on/off).

#### Анимация / переходы

- Появление полосы: смена compact→full **без** анимации ширины панели
  (сразу новая ширина) — иначе «прыгает» панель.
- Исчезновение (dismiss / accept / timeout): мгновенно в «спим».
- Опционально: 200 ms opacity fade на кнопках (не на Layout.width).

#### Взаимодействие с хоткеями

- `Ctrl+1/2/3` / `Ctrl+0` / `Ctrl+.` работают **независимо** от виджета
  (evdev уже перехватывает, пока есть подсказки).
- Виджет лишь отражает то же состояние (`suggest-peek`).

#### Что виджет НЕ делает

- Не появляется поверх окон, не двигается за курсором.
- Не берёт клавиатурный фокус.
- Не пишет и не читает текст ввода (только готовые кандидаты от демона).

---

**Данные:** polling `switchfix suggest-peek` через
`Plasma5Support.DataSource { engine: "executable" }` (Plasma 6 совместим),
Timer ~300–500 ms. Формат — JSON (тот же `SuggestionUi`).

**Команды** (CLI, IPC через уже существующие файлы daemon'а):

| Команда | Действие |
|---------|----------|
| `switchfix suggest-peek` | JSON текущих подсказок (или пусто) |
| `switchfix suggest-accept N` | принять слот N |
| `switchfix suggest-learn` | `+в словарь` |
| `switchfix suggest-dismiss` | скрыть |

Реализация: пишут `switchfix.suggest.cmd` (как это делал bar), daemon
поллит в существующем 400 ms loop и вызывает `SpellService`.

### B2. Удаление floating-окна

- Удалить `switchfix-ui/src/suggestion_bar.rs` как **iced-приложение**
- Оставить/переименовать `run_suggest_bar` → **CLI-фолбэк** (user choice):
  `switchfix suggest-bar` — терминальный/простой режим (можно тот же
  file-IPC reader в цикле, без iced), чтобы работало без плазмоида
- Убрать spawn `suggest-bar` из `run_daemon` (больше не поднимаем окно)

### B3. Установка

- `switchfix setup` / `packaging/install.sh`: копировать plasmoid в
  `~/.local/share/plasma/plasmoids/org.switchfix.suggestions`
- `plasmawindowed org.switchfix.suggestions` для отладки
- В `doctor`: пункт «plasmoid installed» (наличие каталога)

### B4. Меню трея (fallback, дёшево)

В `tray.rs` добавить в `menu()` текущие кандидаты (если есть) —
«1. привет», «2. …», «+в словарь». Работает даже без плазмоида.

## Верификация

1. `cargo test --workspace` — включая новые layout_chars + spell RU-кейсы.
2. `switchfix spell --text 'ghbdtn'` → `1. привет (раскладка)` (было).
3. **Живой тест языка:** daemon + `RUST_LOG=debug`, набрать в Kate
   `приветт ` в RU-раскладке → в логе `suggestion bar show: "приветт" -> ["привет", …]`
   (не ghbdtn/EN).
4. `switchfix suggest-peek` во время подсказок → JSON со слотами.
5. Плазмоид: `plasmawindowed org.switchfix.suggestions` — полоса
   появляется при опечатке, клик заменяет слово + звук.
6. Без плазмоида: меню трея показывает тех же кандидатов.
7. Floating-окно больше **не** появляется.

## Риски

| Риск | Митигация |
|------|-----------|
| Раскладки кроме RU/EN | map только `ru*`; остальные — latin as-is (док) |
| `getLayoutsList` порядок ≠ индекс | тот же список, что и для `setLayout` (уже проверено в doctor) |
| Executable DataSource шумный | peek дешёвый (чтение файла); timer 400 ms |
| Плазмоид не установлен | tray menu + хоткеи + CLI всегда работают |
| `suggest-bar` CLI без UI | пишет подсказки в stdout/уведомление; для отладки |
