# Платформенный слой: единый интерфейс + модули по ОС/DE

## Цель

Задел на будущее: разные модули в зависимости от ОС (Linux / Windows / macOS) и DE (KDE / GNOME) за **единым интерфейсом**. Полная поддержка — только **Kubuntu (Linux + KDE Plasma)**. Остальные — заглушки с внятным `Unsupported`.

**Масштаб (подтверждён):** только платформенный слой. Domain / app / use-cases / UI **не переписываем**. Порты в `switchfix-app/src/ports.rs` остаются единым интерфейсом по возможностям.

**Выбор модуля:** `cfg(target_os)` — ОС; runtime-детект DE (`XDG_CURRENT_DESKTOP`) — KDE vs GNOME внутри Linux.

## Подход

Классический OOP на Rust — **Strategy + Abstract Factory**:

- `Platform` — единый trait платформы (фасад).
- `KdePlatform` / `GnomePlatform` / `WindowsPlatform` / `MacosPlatform` — модули-реализации.
- `create_platform()` — фабрика: compile-time ОС + runtime DE.
- `PlatformServices` — набор `Arc<dyn Port>` на все 8 портов.

Порты не меняем. `Platform` — единая точка входа для **сборки** платформенных реализаций.

Слой живёт в `switchfix-adapters/src/platform/` (новый crate не нужен — adapters уже владеет OS-кодом).

## Целевое дерево модулей

```
crates/switchfix-adapters/src/
  lib.rs                      # pub mod platform + re-экспорт TomlConfigStore/ensure_config
  platform/
    mod.rs                    # Platform, PlatformInfo, PlatformServices, PlatformError,
                              # BuildOptions, OsKind/DesktopKind/SessionKind
    detect.rs                 # parse_desktop/parse_session/detect_os/detect_from/detect
    factory.rs                # create_platform / create_platform_from
    stub.rs                   # UnsupportedPlatform (общий fallback)
    portable/                 # переносимое, без evdev/zbus
      typing_buffer.rs        # SharedTypingBuffer (из evdev_hotkey.rs)
      manual_hotkeys.rs       # ManualHotkeySource (из evdev_hotkey.rs)
      clipboard.rs            # ArboardClipboard (rename WaylandClipboard)
      config_store.rs         # TomlConfigStore + ensure_config + tests
      log_notifier.rs         # LogNotifier (из daemon/wiring.rs)
    linux/                    # #[cfg(target_os = "linux")]
      mod.rs                  # select(info), parse_hotkey_bindings()
      evdev_hotkey.rs         # EvdevHotkeySource, EvdevOptions, key_name_to_code
      uinput_injector.rs      # UinputInjector
      kde/
        mod.rs                # KdePlatform (полная реализация)
        layout.rs             # KdeLayoutSwitcher (+ live #[ignore] test)
      gnome/
        mod.rs                # GnomePlatform — заглушка
    windows/mod.rs            # WindowsPlatform — заглушка (cfg)
```

Старые плоские файлы `clipboard.rs`, `config_store.rs`, `evdev_hotkey.rs`, `kde_layout.rs`, `uinput_injector.rs` — **удалить** после переноса (без compat-шипов).

## API (сигнатуры)

```rust
// platform/mod.rs
pub enum OsKind { Linux, Windows, Macos, Unsupported }
pub enum DesktopKind { Kde, Gnome, Other, Unknown }
pub enum SessionKind { Wayland, X11, Unknown }

pub struct PlatformInfo {
    pub os: OsKind,
    pub desktop: DesktopKind,
    pub session: SessionKind,
    pub id: String,              // "linux/kde/wayland"
    pub supported: bool,         // true только для linux+kde
    pub stub_reason: Option<String>,
}

pub struct BuildOptions { pub allow_evdev: bool, pub allow_uinput: bool }  // = WireOptions

pub struct PlatformServices {
    pub injector: Arc<dyn TextInjector>,
    pub clipboard: Arc<dyn ClipboardPort>,
    pub selection: Arc<dyn SelectionCapture>,   // тот же экземпляр, что clipboard
    pub buffer: Arc<dyn TypingBufferPort>,
    pub layouts: Arc<dyn LayoutSwitcher>,
    pub hotkeys: Box<dyn HotkeySource>,
    pub config: Arc<dyn ConfigStore>,
    pub notifier: Arc<dyn Notifier>,
}

pub enum PlatformError {
    Unsupported { reason: String },
    Injection(String), Layout(String), Hotkeys(String),
    Clipboard(String), Config(String), Other(String),
}

#[async_trait]
pub trait Platform: Send + Sync {
    fn info(&self) -> PlatformInfo;
    async fn build_services(&self, cfg: &AppConfig, opts: &BuildOptions)
        -> Result<PlatformServices, PlatformError>;
}

// detect.rs
pub fn parse_desktop(raw: &str) -> DesktopKind;   // "KDE"|"ubuntu:GNOME"|…
pub fn parse_session(raw: &str) -> SessionKind;
pub fn detect_os() -> OsKind;
pub fn detect_from(os, raw_de, raw_session) -> PlatformInfo;  // чистая, тестируемая
pub fn detect() -> PlatformInfo;                              // из env

// factory.rs
pub fn create_platform() -> Box<dyn Platform>;                // detect + select, не падает
pub fn create_platform_from(info: PlatformInfo) -> Box<dyn Platform>;
```

Фабрика **всегда** возвращает `Box<dyn Platform>` (заглушку для неподдерживаемых), чтобы `doctor` мог напечатать «detected linux/gnome (stub)», а `build_services()` вернул `Unsupported` с подсказкой.

## KdePlatform::build_services

Переиспользует текущие адаптеры (порядок как в `wiring::build`):

1. `SharedTypingBuffer::new(cfg.privacy…)` — portable
2. `KdeLayoutSwitcher::connect()` → `PlatformError::Layout` (сохранить текст «Are you on KDE Plasma?»)
3. `UinputInjector::open()` → `PlatformError::Injection` (сохранить hint про `sudo usermod -aG input $USER`)
4. **второй** `UinputInjector` для clipboard (как сегодня wiring.rs:113–119) + `ArboardClipboard::new(Some(inj), cfg.behavior.copy_settle_ms)`
5. hotkeys: `parse_hotkey_bindings(cfg)` → `EvdevHotkeySource::open_with` (fallback `ManualHotkeySource`)
6. `TomlConfigStore` + `LogNotifier`

**Важно:** `clipboard` и `selection` — два `Arc`-представления **одного** `ArboardClipboard` (`let c = Arc::new(...); clipboard: c.clone() as …, selection: c as …`). Не два клипборда.

## Заглушки

| Среда | Тип | `build_services()` |
|-------|-----|-------------------|
| Linux + KDE | `KdePlatform` | полный `PlatformServices` |
| Linux + GNOME | `GnomePlatform` | `Unsupported` — «GNOME is not implemented yet (planned: XDG Desktop Portal / gsettings). Use KDE Plasma for now.» |
| Linux + другое DE | `UnsupportedPlatform` | `Unsupported` — «desktop … is not supported yet» |
| Windows (cfg) | `WindowsPlatform` | `Unsupported` — «Windows is not implemented yet (planned: SendInput / ImmGetLayout).» |
| macOS (cfg) | `MacosPlatform` | `Unsupported` — «macOS is not implemented yet (planned: CGEvent / TIS).» |

- `zbus`, `evdev`, `futures-lite` → `[target.'cfg(target_os = "linux")'.dependencies]`
- **удалить** мёртвый `wl-clipboard-rs` (также из workspace `Cargo.toml`)

**`crates/switchfix-daemon/Cargo.toml`:** `zbus` → linux target-dep.

## Изменения в daemon

**`wiring.rs`** — `build()` через фабрику:
```
create_platform() → platform.build_services(&cfg, &BuildOptions{from WireOptions})
→ CorrectionService::new(injector, clipboard, selection, buffer, layouts, notifier, tables, config_rx, enabled)
```
Порядок аргументов `CorrectionService::new` — как `correction.rs:36–45` (проверено).
`LogNotifier` уезжает в `platform/portable`. `AppContext.buffer/store` → `Arc<dyn …>`. `spawn_tray_dispatcher` не трогаем.

**`doctor.rs`** — блок «platform»: `id`, `supported`, `stub_reason` (вместо сырых XDG-строк). Linux-пробы (`/dev/uinput`, `input` group, zbus-probe) обернуть в `#[cfg(target_os = "linux")]`.

**`main.rs`** — только правка путей `TomlConfigStore` / `ensure_config` (re-export из crate root).

## Что НЕ меняем

- `switchfix-domain`, `switchfix-app` (порты, `CorrectionService`, config, hotkey) — сигнатуры портов и error-варианты (`InjectError::Device` и т.п.) **не** переименовываем (churn без выгоды)
- `switchfix-ui` (ksni tray, iced settings)
- `switchfix-tests` (fakes/сценарии ходят через порты)
- packaging, docs
- Реальную GNOME/Windows/macOS-реализацию

**Новые unit-тесты** в `switchfix-adapters` (~15):

## Риски / подводные камни

1. **`evdev::KeyCode` leak** — `key_name_to_code` остаётся внутри `platform/linux`, не реэкспортируем наружу.
2. **Дубль буфера** — adapters `SharedTypingBuffer` ≠ domain `TypingBuffer`. В рамках задачи только переносим в `portable/`, не унифицируем. `EvdevOptions.buffer` остаётся `Arc<SharedTypingBuffer>` (нужны `push`/`pop`), erase в `dyn` только на границе `PlatformServices`.
3. **Второй uinput для clipboard** — сохранить поведение (отдельный `UinputInjector`), не переиспользовать один Arc.
4. **Один clipboard, два Arc-вида** — иначе сломается marker-протокол `last_save`.
5. **doctor zbus-probe** в daemon — cfg-gate вместе с переносом dep, иначе не-Linux сборка сломается.
6. **windows/macos заглушки** не скомпилируются на этом хосте — отметить «не проверено», если нет cross-target.
7. **`HotkeySource::events()`** — `take()` один раз; не вызывать в `build_services`.
8. **Пользовательские тексты ошибок** сохранить («Run: sudo usermod -aG input $USER», «Are you on KDE Plasma?»).
9. **`ksni`/`iced`** остаются Linux-oriented — вне scope (cfg потом, когда понадобится Windows-сборка).
