# SwitchFix: оставить только хорошее

Убрать плохо сделанные функции (автозамены, подсказки при вводе, встроенный LLM). Оставить:
1. **Переворот раскладки** выделенного текста по хоткею (EN↔RU) + tray + toggle + flash/звук.
2. **LLM-исправление выделенного** через **внешний OpenAI-compatible API** (хост, токен, системный промпт). Замена выделения результатом; **1×Backspace в течение ~4 с полностью отменяет замену**.

## 2. OpenAiCorrector + узкий порт

### Порт (`crates/switchfix-app/src/ports.rs`)

Заменить `ContextCorrector`/`ContextFix`/`SpellChecker`/`SuggestionPresenter`/`SpellError` на:

```rust
pub enum TextFixError { Http(String), Api(String), Parse(String) }

#[async_trait]
pub trait TextCorrector: Send + Sync {
    fn name(&self) -> &'static str;
    async fn correct_text(&self, text: &str) -> Result<String, TextFixError>;
}
```

`WordEvent` оставить только `{ Backspace, Updated }` — Backspace для undo, Updated чтобы сбрасывать undo при наборе.

### HTTP-клиент: `ureq` + `spawn_blocking`

- Существующий `reqwest_like` — **http:// + localhost only**, не умеет HTTPS. Не тянуть TLS руками.
- **Решение:** зависимость `ureq = { version = "2", features = ["json"] }` в `switchfix-adapters`, вызов через `tokio::task::spawn_blocking` (не блокировать runtime).
- Новый файл: `crates/switchfix-adapters/src/platform/portable/openai_corrector.rs`.
- Удалить `context_correctors.rs` (ProcessCorrector, LanguageToolCorrector, reqwest_like).

### API

```
POST {base_url}/v1/chat/completions
Authorization: Bearer {api_token}   // если token non-empty
{
  "model": "...",                   // omit если пустой
  "messages": [
    {"role":"system","content":"<system_prompt>"},
    {"role":"user","content":"<выделенный текст>"}
  ]
}
```

- Парсинг: `choices[0].message.content`, trim. Пустой content → `Api("empty completion")`.
- Чистые функции `build_request_json` / `parse_response` — юнит-тесты без HTTP.
- **Токен никогда не логировать** (только base_url + model).

### Wiring (`crates/switchfix-daemon/src/wiring.rs`)

- `OpenAiCorrector::new(&cfg.llm)` когда `llm.enabled && !base_url.is_empty()`.
- `service.set_text_corrector(...)` (rename `set_context_corrector`).
- **Reload gap fix:** при soft-reload (`main.rs` ~598–605) пересобирать corrector из свежего `cfg.llm`.

## 3. Undo: 1 Backspace = полный откат

**Внутри `CorrectionService`** (`correction.rs`), шаблон из `spell.rs:55–68, 735–800`:

```rust
struct UndoState { original: String, replacement: String, when: Instant }
const UNDO_WINDOW: Duration = Duration::from_secs(4);
// поля: undo: Mutex<Option<UndoState>>, suppress: AtomicBool
```

**Arm** — только после успешного `llm_fix_selection` → `replace_with_text(..., arm_undo: true)`:
запомнить `{original, replacement=new_text, now}` + `buffer.set_contents(&new_text)`.

**Restore (`on_backspace`)** — cursor уже после pasted text, selection нет:
1. Take undo если `elapsed() <= UNDO_WINDOW`, иначе clear + return.
2. Physical BS уже съел 1 символ → `remaining = replacement.chars().count() - 1`.
3. `suppress=true`; `wait_keys_quiet(50, 500)`; `injector.backspace(remaining)`.
4. `type_text(original)` c layout из `detect_lang(original)` (`"ru"`/`"us"`).
5. `buffer.set_contents(original)`; `suppress=false`; clear undo.

**Clear:** окно истекло · `on_typing` (любой ввод) · toggle-off · новая LLM-замена · после use.

**Сигнал Backspace:**
- `evdev_hotkey.rs:533–535` KEY_BACKSPACE → `buffer.pop()` → `WordEvent::Backspace`.
- **Ungate:** `SharedTypingBuffer::pop` (`typing_buffer.rs:124–130`) сейчас шлёт событие только при `privacy.typing_buffer=true`. Перенести `word_tx.send(Backspace)` **вне** этого гейта (сигнал, не хранение текста). Undo обязан работать при выключенном typing_buffer.
- Daemon loop (`main.rs:457–474`): вместо SpellService → `service.on_backspace()` / `service.on_typing()`.

|---|---|
| systemd `RestrictAddressFamilies` блокирует TCP | Добавить `AF_INET AF_INET6` в unit |

| Clipboard verify fail → Ctrl+V стирает selection | Keep `get_text()` verify + type_text fallback |
