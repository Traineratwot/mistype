# Fix Plasma widget: `ScrollView is not a type`

## Problem
`packaging/plasmoid/org.switchfix.suggestions/contents/ui/main.qml:120` — `ScrollView` is used without an import. Plasma 6 / Qt 6 does not export it via `QtQuick` or `org.kde.plasma.components`.

## Fix
1. Add import: `import QtQuick.Controls as QQC2`
2. Replace `ScrollView { ... }` with `QQC2.ScrollView { ... }`
3. Keep layout: `Layout.fillWidth` / `Layout.maximumHeight` on the scroll view; inner `ColumnLayout` should use `width: parent.width` **or** `Layout.preferredWidth` so rows fill the popup.

## Files
- `packaging/plasmoid/org.switchfix.suggestions/contents/ui/main.qml`
- Copy same file to installed widget: `~/.local/share/plasma/plasmoids/org.switchfix.suggestions/contents/ui/main.qml`

## Verification
- `plasmawindowed org.switchfix.suggestions` or reload plasmashell — no `ScrollView is not a type` in `journalctl --user -f | grep qml`
- Popup shows history list and scrolls when > ~3 items
