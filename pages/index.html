Mistype

Fix text typed in the wrong keyboard layout (EN↔RU) — Linux/KDE answer to Punto Switcher.

Install (Debian / Ubuntu / Kubuntu)

echo "deb [trusted=yes] __PAGES_BASE__ ./" \
  | sudo tee /etc/apt/sources.list.d/mistype.list
sudo apt update
sudo apt install mistype

Or download the .deb below and run sudo apt install ./mistype_*.deb.

After install

mistype setup      # group 'input' + udev rule (prompts for sudo only when needed)
mistype doctor     # diagnostics: platform, hotkeys, D-Bus, sound
mistype selftest   # inject ctrl+f20 via uinput, verify evdev intercept

Enable the tray daemon when ready (not enabled automatically):

systemctl --user enable --now mistype

Global hotkeys need group input. Run mistype setup or sudo usermod -aG input $USER and re-login. Hotkeys are configured in ~/.config/mistype/config.toml — restart the daemon after changes.

Packages (apt)

Source, issues and checksums are on GitHub · downloads and release notes on Releases.

Privacy: no network, no keylogging persistence. The keystroke buffer is RAM-only and optional. See /usr/share/doc/mistype/PRIVACY.md.
