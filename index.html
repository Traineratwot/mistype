SwitchFix

Fix text typed in the wrong keyboard layout (EN↔RU) — Linux/KDE answer to Punto Switcher.

Install (Debian / Ubuntu / Kubuntu)

echo "deb [trusted=yes] https://Traineratwot.github.io/switchfix ./" \
  | sudo tee /etc/apt/sources.list.d/switchfix.list
sudo apt update
sudo apt install switchfix

Or download the .deb below and run sudo apt install ./switchfix_*.deb.

After install

switchfix setup      # group 'input' + udev rule (prompts for sudo only when needed)
switchfix doctor     # diagnostics: platform, hotkeys, D-Bus, sound
switchfix selftest   # inject ctrl+f20 via uinput, verify evdev intercept

Enable the tray daemon when ready (not enabled automatically):

systemctl --user enable --now switchfix

Global hotkeys need group input. Run switchfix setup or sudo usermod -aG input $USER and re-login. Hotkeys are configured in ~/.config/switchfix/config.toml — restart the daemon after changes.
